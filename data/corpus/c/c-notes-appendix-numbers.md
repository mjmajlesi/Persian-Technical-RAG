# پیوست الف: نمایش اعداد در حافظه (مکمل دو)

(مکمل فصل ۴ — بخش «چرا بازه signed با unsigned فرق دارد؟»)

## الف.۱ — بیت، بایت و مبناهای شمارش

هر بایت ۸ بیت است. سه مبنای پرکاربرد در C:

| مبنا | پیشوند لیترال | ارقام | مثال |
|------|---------------|-------|------|
| دهدهی | — | 0–9 | `42` |
| شانزده‌دهی (hex) | `0x` | 0–9, A–F | `0x2A` = ۴۲ |
| هشت‌دهی (octal) | `0` | 0–7 | `052` = ۴۲ |
| دودویی | `0b` (استاندارد C23) | 0–1 | `0b101010` = ۴۲ |

**تله صفر ابتدای عدد:** `052` در C یعنی اوکتال (۴۲ دهدهی)، نه پنجاه‌ودو!

```c
int a = 42;       // دهدهی
int b = 0x2A;     // هگز: همان ۴۲
int c = 052;      // اوکتال: باز هم ۴۲!
int d = 0b101010; // دودویی (C23): همان ۴۲
```

## الف.۲ — اعداد بدون علامت (unsigned)

n بیت بدون علامت، بازه `[0, 2^n − 1]`:

| نوع | بیت | بازه |
|-----|-----|------|
| `unsigned char` | ۸ | ۰ تا ۲۵۵ |
| `unsigned short` | ۱۶ | ۰ تا ۶۵۵۳۵ |
| `unsigned int` | ۳۲ | ۰ تا ۴۲۹۴۹۶۷۲۹۵ |

سرریز unsigned **تعریف‌شده و چرخشی** است: `255u + 1` در یک بایت می‌شود ۰.

## الف.۳ — مکمل دو (Two's Complement) برای signed

اعداد علامت‌دار با **مکمل دو** ذخیره می‌شوند: باارزش‌ترین بیت، علامت است (۰=مثبت، ۱=منفی).

**قاعده ساختن منفی یک عدد:** همه بیت‌ها را وارونه کن، بعد ۱ اضافه کن:

```text
عدد ۵ در ۸ بیت:        0000 0101
وارونه (مکمل یک):      1111 1010
به‌علاوه ۱ (مکمل دو):  1111 1011  ← نمایش ‎−۵
```

بازه n بیت علامت‌دار: `[-2^(n-1), 2^(n-1) − 1]` — نامتقارن است (یک منفی بیشتر):

| نوع | بیت | بازه |
|-----|-----|------|
| `signed char` | ۸ | −۱۲۸ تا ۱۲۷ |
| `short` | ۱۶ | −۳۲۷۶۸ تا ۳۲۷۶۷ |
| `int` | ۳۲ | −۲۱۴۷۴۸۳۶۴۸ تا ۲۱۴۷۴۸۳۶۴۷ |

**چرا −۱۲۸ هست ولی +۱۲۸ نیست؟** الگوی `1000 0000` که در unsigned می‌شد ۱۲۸، در signed منفی‌ترین عدد (−۱۲۸) است؛ الگوی مثبتِ ۱۲۸ (`01000 0000` نه‌بیت می‌خواهد) در ۸ بیت جا نمی‌شود.

```c
signed char s = 127;
s = s + 1;    // سرریز signed = رفتار تعریف‌نشده! (عملاً معمولاً −۱۲۸)
```

## الف.۴ — مقایسه signed و unsigned در عبارت‌ها

در عبارت‌های مختلط، signed به unsigned تبدیل می‌شود — **تله کلاسیک**:

```c
unsigned int u = 10;
int i = -20;
if (i < u)
    printf("i smaller");   // چاپ نمی‌شود!
else
    printf("u smaller or equal");  // همین چاپ می‌شود!
```

چرا؟ `i` به unsigned تبدیل شد و ‎−۲۰‎ شد عددی غول‌پیکر (~۴ میلیارد). قانون: **هرگز signed و unsigned را مستقیم مقایسه نکنید** مگر مطمئن باشید هر دو غیرمنفی‌اند.

## الف.۵ — خلاصه حفظی

- unsigned: `[0, 2^n − 1]`، سرریز چرخشی و تعریف‌شده
- signed (مکمل دو): `[-2^(n-1), 2^(n-1) − 1]`، سرریز **تعریف‌نشده**
- منفی کردن = وارونه + ۱؛ `~x + 1 == -x`
- در عبارت مختلط، signed به unsigned ارتقا می‌یابد (مراقب مقایسه‌ها!)
