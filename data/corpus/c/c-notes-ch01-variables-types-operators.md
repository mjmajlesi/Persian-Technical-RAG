# فصل ۴: متغیرها، انواع داده و عملگرها


## ۴.۱ — شناسه‌ها (Identifiers) و قواعد نام‌گذاری

**شناسه:** نامی که به متغیر، تابع یا نوع می‌دهیم.

قواعد:
1. فقط حروف، ارقام و زیرخط (`_`)
2. **اولین کاراکتر نمی‌تواند رقم باشد**
3. C حساس به حروف بزرگ/کوچک است: `sum` ≠ `Sum` ≠ `SUM`
4. **کلمات کلیدی (Keywords) قابل استفاده نیستند**

```c
// ✅ معتبر
int count, _temp, x2, total_sum;

// ❌ نامعتبر
// int 2x;        // شروع با رقم
// int my-var;    // خط تیره مجاز نیست
// int float;     // کلمه کلیدی
```

### ۳۲ کلمه کلیدی استاندارد C89

| | | | |
|---|---|---|---|
| `auto` | `break` | `case` | `char` |
| `const` | `continue` | `default` | `do` |
| `double` | `else` | `enum` | `extern` |
| `float` | `for` | `goto` | `if` |
| `int` | `long` | `register` | `return` |
| `short` | `signed` | `sizeof` | `static` |
| `struct` | `switch` | `typedef` | `union` |
| `unsigned` | `void` | `volatile` | `while` |

**نکته کنکوری**

`printf`، `scanf`، `main`، `size_t` کلمه کلیدی **نیستند** — توابع کتابخانه‌ای هستند! اما نباید نام متغیرتان را هم بگذارید (تعارض ایجاد می‌شود). کلمات جدید C99/C11: `inline`, `restrict`, `_Bool` و...

## ۴.۲ — انواع داده اصلی (Basic Data Types)

### چهار نوع اصلی + اصلاح‌کننده‌ها

انواع اصلی: `int`, `float`, `double`, `char`
اصلاح‌کننده‌ها: `short`, `long`, `signed`, `unsigned`

| نوع              | اندازه معمول (GCC x86-64)  | بازه                                    | مشخصات قالب printf               |
| ---------------- | -------------------------- | --------------------------------------- | -------------------------------- |
| `char`           | ۱ بایت                     | −۱۲۸ تا ۱۲۷                             | `%c` (کاراکتر) / `%d` (کد ASCII) |
| `unsigned char`  | ۱ بایت                     | ۰ تا ۲۵۵                                | `%u`                             |
| `short int`      | ۲ بایت                     | −۳۲۷۶۸ تا ۳۲۷۶۷                         | `%hd`                            |
| `unsigned short` | ۲ بایت                     | ۰ تا ۶۵۵۳۵                              | `%hu`                            |
| `int`            | ۴ بایت                     | ±۲.۱۴ میلیارد ($-2^{31}$ تا $2^{31}-1$) | `%d`                             |
| `unsigned int`   | ۴ بایت                     | ۰ تا ~۴.۲۹ میلیارد                      | `%u`                             |
| `long int`       | لینوکس: ۸ / ویندوز: ۴ بایت | —                                       | `%ld`                            |
| `long long int`  | ۸ بایت                     | $\pm9.2 \times 10^{18}$                 | `%lld`                           |
| `float`          | ۴ بایت                     | ~±$10^{38}$، دقت ~۷ رقم                 | `%f`                             |
| `double`         | ۸ بایت                     | ~±$10^{308}$، دقت ~۱۵ رقم               | `%lf`                            |


**قاعده اندازه‌ها (مهم برای تست)**

استاندارد C حداقل‌ها را تعیین می‌کند؛ رابطه همیشگی:
$$\text{sizeof(char)} = 1 \le \text{sizeof(short)} \le \text{sizeof(int)} \le \text{sizeof(long)} \le \text{sizeof(long long)}$$

و برای ممیز شناور: `sizeof(float) ≤ sizeof(double) ≤ sizeof(long double)`

در تست اگر گزینه‌ای گفت «اندازه int همیشه دقیقاً ۴ بایت است» → غلط! استاندارد فقط می‌گوید «معمولاً». اما در سؤالات محاسباتی، int را ۴ بایتی فرض کنید مگر خلاف آن گفته شود.


### چرا بازه signed با unsigned فرق دارد؟

فصل ۲ یادت هست: signed از مکمل دو استفاده می‌کند و بیت آخر علامت است:

```text
unsigned char: 8 بیت همگی داده   → [0, 255]
signed char:   1 بیت علامت + 7 داده → [−128, +127]
```

```c
#include <stdio.h>

int main(void)
{
    unsigned char u = 255;
    u = u + 1;                 // سرریز: به 0 برمی‌گردد!
    printf("%u\n", u);         // 0

    signed char s = 127;
    s = s + 1;                 // UB در تئوری؛ عملاً −128
    return 0;
}
```

**رفتار چرخشی unsigned**

اعداد بدون علامت مثل ساعت کار می‌کنند: از بالای بازه که خارج شوند از پایین ادامه می‌دهند. `0u - 1` می‌شود عدد بسیار بزرگ (4294967295). این رفتار برای unsigned **تعریف‌شده** است ولی برای signed **Undefined Behavior**!


### نوع char — پل بین کاراکتر و عدد

`char` واقعاً یک عدد صحیح کوچک است که کد **ASCII** ذخیره می‌کند:

```c
char c = 'A';
printf("%d\n", c);   // 65  (کد اسکی)
printf("%c\n", c);   // A
printf("%c\n", c + 2); // C  ← حساب روی کاراکتر!
```

چند کد مهم: `'A'`=65, `'a'`=97, `'0'`=48, فاصله=32.
ترفند: `'a' - 'A' = 32`؛ تبدیل کوچک→بزرگ: `c - 32` یا `c - 'a' + 'A'`.

## ۴.۳ — متغیرها: تعریف، اعلان و مقداردهی

**متغیر:** خانه‌ای در حافظه با نام، نوع و مقدار (که می‌تواند تغییر کند).

```c
int a;                    // تعریف (فضا رزرو شد؛ مقدار نامشخص!)
int b = 5;                // تعریف + مقداردهی اولیه
int c = 3, d = c + 1;     // چند تعریف در یک خط
float rate = 18.5f;
char grade = 'A';
```

**مقداردهی اولیه نکردن**

متغیر محلیِ مقداردهی نشده **مقدار آشغال (garbage)** دارد — هر عددی ممکن است باشد. استفاده از آن Undefined Behavior است و منبع کلاسیک سؤالات «خروجی نامشخص» است.


### تعریف vs اعلان (پیش‌نگاه فصل توابع)

- **تعریف (Definition):** فضا رزرو می‌کند → `int x;`
- **اعلان (Declaration):** فقط معرفی می‌کند → `extern int x;`
- هر تعریفی خودش یک اعلان هم هست، ولی برعکس نه.

## ۴.۴ — ثابت‌ها: const و #define

دو راه تعریف مقدار تغییرناپذیر:

```c
#define PI 3.14159          // پیش‌پردازنده: جایگذاری متنی قبل از کامپایل

const double E = 2.71828;   // کامپایلر: متغیر واقعیِ فقط‌خواندنی
```

| ویژگی | `#define` | `const` |
|--------|-----------|---------|
| چه زمانی پردازش می‌شود؟ | مرحله پیش‌پردازش | مرحله کامپایل |
| نوع دارد؟ | ندارد (جایگذاری متنی!) | دارد |
| فضای حافظه می‌گیرد؟ | نه (در کد جاسازی می‌شود) | معمولاً بله |
| با اشاره‌گر قابل دسترسی؟ | — | بله ولی تغییرش UB |

```c
#include <stdio.h>
#define MAX 100

int main(void)
{
    const int MIN = 1;
    printf("Max=%d Min=%d\n", MAX, MIN);
    return 0;
}
```

## ۴.۵ — عملگرهای انتساب

```c
int a = 5;       // = انتساب (نه تساوی ریاضی!)

a += 3;          // a = a + 3  → 8
a -= 2;          // a = a - 2  → 6
a *= 4;          // a = a * 4  → 24
a /= 5;          // a = a / 5  → 4  (تقسیم صحیح!)
a %= 3;          // a = a % 3  → 1
```

**انتساب خودش یک عبارت است!**

`=` یک مقدار تولید می‌کند (همان مقداری که منتسب شد) و **از راست به چپ** اجرا می‌شود:

```c
int x, y, z;
x = y = z = 7;      // سه‌تایی ۷ می‌شوند (z=7 بعد y=z بعد x=y)

if ((c = getchar()) != EOF)   /* الگوی رایج C */
```

## ۴.۶ — عملگرهای محاسباتی

| عملگر | کاربرد | مثال | نتیجه |
|--------|---------|------|-------|
| `+` `-` | جمع/تفریق | `7 - 3` | ۴ |
| `*` | ضرب | `4 * 2` | ۸ |
| `/` | تقسیم | `7 / 2` | **۳** ⚠️ |
| `%` | باقیمانده (mod) | `7 % 2` | ۱ |
| `++` | افزایش واحد | `++a` / `a++` | — |
| `--` | کاهش واحد | `--a` / `a--` | — |

### تقسیم صحیح در مقابل اعشاری ⭐ پرتکرارترین تله کنکور

**قانون طلایی:** اگر **هر دو عملوند int** باشند → تقسیم صحیح (بخش صحیح فقط):

```c
int a = 7 / 2;        // 3  (نه 3.5!)
float b = 7 / 2;      // 3.0  ← هنوز صحیح تقسیم شده، بعد تبدیل!
float c = 7 / 2.0;    // 3.5 ✓ یکی اعشاری بود
float d = (float)7 / 2;  // 3.5 ✓ cast روی یکی کافی است
```

**تله کلاسیک**

`float f = 7 / 2;` نتیجه **۳٫۰** است نه ۳٫۵! چون سمت راست مستقل محاسبه می‌شود (۷÷۲=۳)، بعد به float تبدیل می‌شود.


### عملگر %

- فقط برای **اعداد صحیح** است (`7.5 % 2` خطا دارد).
- علامت نتیجه در C99 = **علامت عملگر سمت چپ**: `-7 % 2 = -1` ، `7 % -2 = 1`

### ++ و −− : پیشوند vs پسوند ⭐⭐

| حالت | نام | رفتار | مثال (a=5) |
|-------|------|-------|------------|
| `++a` | پیشوند (pre-increment) | اول افزایش، **بعد** استفاده | `b = ++a;` → b=6, a=6 |
| `a++` | پسوند (post-increment) | اول استفاده، **بعد** افزایش | `b = a++;` → b=5, a=6 |

```c
int a = 5, b;
b = ++a + a;    // ⚠️ UB! بین دو نقطه ترتیب بیش از یک تغییر a
b = ++a;        // امن: a=6 سپس b=6
b = a++;        // امن: b=6 سپس a=7
```

**Undefined Behavior واقعی**

عباراتی مثل `i = i++ + 1;` یا `a[i++] = i;` رفتار **تعریف‌نشده** دارند (تغییر یک متغیر بیش از یک بار در یک عبارت). در کنکور معمولاً از این‌ها سؤال نمی‌آید مگر اینکه طراح خودش بی‌اطلاع باشد؛ ولی در پروژه هرگز ننویسید.

## ۴.۷ — اولویت و شرکت‌پذیری عملگرها ⭐⭐⭐

وقتی چند عملگر داریم: اولویت بالاتر زودتر اجرا می‌شود؛ در تساوی اولویت، **شرکت‌پذیری (Associativity)** تعیین می‌کند.

جدول خلاصه (از بالاترین اولویت):

| اولویت | عملگرها | شرکت‌پذیری |
|---------|----------|-------------|
| ۱ | `()` `[]` `->` `.` | چپ→راست |
| ۲ | `!` `~` `++` `--` unary `-+` `(cast)` `sizeof` `&`(آدرس) `*`(اشاره‌گر) | **راست→چپ** |
| ۳ | `*` `/` `%` | چپ→راست |
| ۴ | `+` `-` | چپ→راست |
| ۵ | `<<` `>>` | چپ→راست |
| ۶ | `<` `<=` `>` `>=` | چپ→راست |
| ۷ | `==` `!=` | چپ→راست |
| ۸ | `&` (بیتی AND) | چپ→راست |
| ۹ | `^` | چپ→راست |
| ۱۰ | `\|` | چپ→راست |
| ۱۱ | `&&` | چپ→راست |
| ۱۲ | `\|\|` | چپ→راست |
| ۱۳ | `? :` | **راست→چپ** |
| ۱۴ | `=` `+=` `-=` ... | **راست→چپ** |
| ۱۵ | `,` | چپ→راست |

**جمله حفظی**

**«یک‌تایی، ضرب‌ها، جمع‌ها، شیفت‌ها، مقایسه بزرگ‌ترها، مقایسه مساوی‌ها، & ^ | ، && || ، شرط، انتساب»**


مثال‌های تحلیلی:

```c
int r = 2 + 3 * 4 % 5;      // ضرب/mod اول: 12%5=2 → 2+2 = 4
int s = 10 - 4 - 3;         // چپ‌به‌راست: 6-3 = 3
int t = -3 * -2;            // 6 (منفی یک‌تایی بالاتر از *)
int u = 5 > 3 == 1;         // 5>3 اول: 1 ؛ 1==1: 1
int v = 1 << 2 + 1;         // جمع اول! 1 << 3 = 8  (نه 5)
```

**تله معروف: `==` و `=`**

```c
if (x = 5)    // انتساب! همیشه درست (عدد غیرصفر) — باگ مشهور C
if (x == 5)   // مقایسه صحیح
```
کامپایلر با هشدار `-Wall` این را گوشزد می‌کند.

## ۴.۸ — عملگرهای مقایسه‌ای و منطقی

| عملگر | معنا | نتیجه |
|--------|------|-------|
| `<` `>` `<=` `>=` | مقایسه | ۱ (درست) یا ۰ (غلط) |
| `==` `!=` | برابری/نابرابری | ۱ یا ۰ |
| `&&` | و منطقی (هر دو لازم) | ۱ یا ۰ |
| `\|\|` | یا منطقی (یکی کافی) | ۱ یا ۰ |
| `!` | نفی منطقی | ۱ یا ۰ |

**مفهوم درستی/نادرستی در C**

**هر عدد غیرصفر = درست، صفر = غلط.** نتیجه مقایسه/منطقی همیشه int از {0,1} است.


### ارزیابی اتصال‌کوتاه (Short-Circuit Evaluation) ⭐⭐⭐

`&&` و `||` **تنبل** هستند:

- `A && B`: اگر A غلط باشد، B اصلاً ارزیابی **نمی‌شود** (جواب قطعاً ۰ است).
- `A || B`: اگر A درست باشد، B ارزیابی نمی‌شود.

```c
int i = 0, j = 0;

(i > 0) && (j++);    // j++ اجرا نمی‌شود! چون i>0 غلط است
(i == 0) || (j++);   // باز هم j++ اجرا نمی‌شود (اولی درست)

printf("%d %d\n", i, j);  // 0 0
```

**مثال کنکوری:**

```c
int a = 1, b = 2, c = 3;
int r = (a = 0) && (b = 5) || (c = 9);
// a=0 (غلط) → b=5 اجرا نمی‌شود → عبارت اول 0
// || → باید سمت راست ارزیابی شود → c=9 (درست=1)
// نتیجه: r=1, a=0, b=2 (تغییر نکرد!), c=9
```

این الگو در C برای محافظت استفاده می‌شود: `if (p != NULL && p->value > 0)` — اول null-check بعد dereference.

## ۴.۹ — تبدیل نوع (Type Conversion)

### الف) تبدیل ضمنی (Implicit — خودکار)

قواعد «ارتقای معمولی»: در یک عبارت، نوع کوچک‌تر به بزرگ‌تر ارتقا می‌یابد:

```text
char/short → int → unsigned int → long → long long → float → double → long double
```

```c
int i = 5;
double d = i;           // 5.0 — بدون مشکل
double x = 3 / 2;       // 1.0 (تقسیم اول انجام شد!)
double y = 3 / 2.0;     // 1.5
```

### ب) تبدیل صریح (Explicit — Cast)

```c
double pi = 3.99;
int k = (int)pi;          // 3  ← گرد نمی‌شود؛ بخش صحیح فقط!
int m = (int)(pi + 0.5);  // 4  ← ترفند گرد کردن به نزدیک‌ترین
char ch = (char)65;       // 'A'
```

**تبدیل double→int**

همیشه **به سمت صفر قطع** می‌شود: `(int)-3.7` می‌شود **−۳** (نه −۴!). برای گرد کردن دستی ±0.5 اضافه کنید.


### ج) ارتقای integer در محاسبات

```c
char a = 100, b = 100;
int s = a + b;    // 200 ✓ چون char ها موقع محاسبه به int ارتقا می‌یابند
char c2 = a + b;  // ⚠️ 200 در char نمی‌گنجد → پیاده‌سازی‌محور (عملاً -56)
```

## ۴.۱۰ — sizeof

عملگری که **اندازه بر حسب بایت** یک نوع یا عبارت را می‌دهد؛ نتیجه‌اش از نوع `size_t` است:

```c
printf("%zu\n", sizeof(int));       // 4
printf("%zu\n", sizeof(double));    // 8
char ch;
printf("%zu\n", sizeof(ch));        // 1  (خود char)
printf("%zu\n", sizeof(ch + ch));   // 4  (چون ارتقا به int!)
```

`sizeof` در زمان کامپایل محاسبه می‌شود (برای انواع) و تابع نیست — پرانتزش وقتی روی نوع به‌کار می‌رود اجباری است، روی عبارت اختیاری: `sizeof x`.

## ۴.۱۱ — ورودی/خروجی پایه: printf و scanf (نسخه مقدماتی)

(قالب‌بندی پیشرفته در فصل ۵ — قالب‌بندی ورودی و خروجی)

```c
int age;
float h;
scanf("%d", &age);      // & یعنی آدرس متغیر — فراموش کردنش باگ کلاسیک!
scanf("%f", &h);
printf("Age=%d Height=%.1f\n", age, h);
```

**فراموش کردن &**

`scanf("%d", age);` بدون `&` → برنامه کرش می‌کند یا رفتار عجیب دارد. scanf **آدرس** می‌خواهد تا مقدار را داخلش بنویسد. (چرایی کامل: فصل اشاره‌گرها.)

## 💻 تمرین‌های کدنویسی فصل ۴

**تمرین ۱:** برنامه‌ای بنویسید که دو عدد صحیح بگیرد و جمع، تفریق، ضرب، تقسیم صحیح و باقیمانده را چاپ کند.

**پاسخ تمرین ۱**

```c
#include <stdio.h>

int main(void)
{
    int a, b;
    printf("Enter two integers: ");
    scanf("%d %d", &a, &b);

    printf("%d + %d = %d\n", a, b, a + b);
    printf("%d - %d = %d\n", a, b, a - b);
    printf("%d * %d = %d\n", a, b, a * b);
    if (b != 0) {
        printf("%d / %d = %d\n", a, b, a / b);
        printf("%d %% %d = %d\n", a, b, a % b);   // %% برای چاپ خود %
    } else {
        printf("Cannot divide by zero!\n");
    }
    return 0;
}
```
نکته: چاپ `%` داخل printf نیاز به `%%` دارد. تقسیم بر صفر هم قبلش چک شد.


**تمرین ۲:** برنامه‌ای که دما را سلسیوس بگیرد و فارنهایت چاپ کند: F = C×9/5 + 32

**پاسخ تمرین ۲**

```c
#include <stdio.h>

int main(void)
{
    float c;
    printf("Celsius: ");
    scanf("%f", &c);
    printf("Fahrenheit = %.1f\n", c * 9 / 5 + 32);
    return 0;
}
```
دقت: چون `c` اعشاری است، `c * 9 / 5` چپ‌به‌راست با محاسبه اعشاری انجام می‌شود و مشکلی ندارد؛ اما اگر همه عملوند int بودند (مثلاً `9 / 5 * ...`)، تقسیم صحیح نتیجه را خراب می‌کرد و باید `9.0 / 5` یا cast می‌نوشتیم. **ترتیب عملوندها را همیشه با نوع‌شان تحلیل کنید.**


**تمرین ۳:** خروجی این برنامه را **بدون اجرا** پیش‌بینی کنید، بعد اجرا و مقایسه کنید:
```c
#include <stdio.h>

int main(void)
{
    int a = 7, b = 2;
    float f1 = a / b;
    float f2 = (float)a / b;
    int c = -17 % 5;

    printf("%f %.2f %d\n", f1, f2, c);
    printf("%d\n", a++ * --b);
    printf("%d %d\n", a, b);
    return 0;
}
```

**پاسخ تمرین ۳**

- خط ۱: `3.000000 3.50 -2` (تقسیم صحیح ۷/۲=۳؛ cast → ۳٫۵۰؛ −17%5 = −2 چون علامت چپ)
- خط 2: `a++` مقدار ۷ می‌دهد، `--b` اول b=1 بعد استفاده → 7×1 = **7** چاپ می‌شود
- خط 3: a=8 و b=1 → `8 1`
