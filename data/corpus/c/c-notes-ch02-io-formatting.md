# فصل ۵: قالب‌بندی ورودی و خروجی

## ۵.۱ — آناتومی مشخص‌کننده قالب (Format Specifier)

ساختار کامل یک مشخص‌کننده در printf:

```text
%[پرچم‌ها][عرض میدان][.دقت][طول]نوع
   flags    width   .precision length  specifier
```

مثال: `%+-8.2lf` یعنی: پرچم‌های `+` و `-`، عرض ۸، دقت ۲، نوع long double.

### جدول انواع (Specifiers)

| نوع | کاربرد | مثال |
|------|--------|------|
| `%d` / `%i` | عدد صحیح علامت‌دار | `%d` ← `42` |
| `%u` | صحیح بدون علامت | `%u` ← `4294967295` |
| `%o` | اوکتال (بدون صفر ابتدا) | `%o` با ۸ ← `10` |
| `%x` / `%X` | هگز کوچک/بزرگ | `%x` با ۲۵۵ ← `ff` |
| `%f` | ممیز شناور اعشاری | `%f` ← `3.140000` |
| `%e` / `%E` | نماد علمی | `1.234568e+05` |
| `%g` / `%G` | کوتاه‌ترین بین f و e | `123456.789` ← `123457` |
| `%c` | یک کاراکتر | `A` |
| `%s` | رشته | `Hello` |
| `%p` | آدرس اشاره‌گر | `0x7ffd...` |
| `%%` | چاپ خودِ `%` | `%` |

### طول (Length Modifiers)

| طول | معنا | جفتِ درست |
|------|------|-----------|
| `l` | long | `%ld` برای long, `%lf` برای double **در scanf** |
| `ll` | long long | `%lld` |
| `h` | short | `%hd` |

**مهم‌ترین تله: %f و %lf**

- در **printf**: هر دو float و double با `%f` چاپ می‌شوند (float خودبه‌خود به double ارتقا می‌یابد).
- در **scanf**: double حتماً `%lf` می‌خواهد! `scanf("%f", &d)` برای double رفتار تعریف‌نشده دارد — باگ کلاسیک و سؤال کلاسیک.

## ۵.۲ — عرض میدان (Field Width)

حداقل تعداد کاراکتر چاپی؛ اگر کوتاه‌تر بود، **با فاصله پر می‌شود** (راست‌چین به‌طور پیش‌فرض):

```c
#include <stdio.h>

int main(void)
{
    printf("[%d]\n", 42);      // [42]
    printf("[%5d]\n", 42);     // [   42]   ← ۳ فاصله قبل
    printf("[%-5d]\n", 42);    // [42   ]   ← چپ‌چین با پرچم -
    printf("[%05d]\n", 42);    // [00042]   ← پر با صفر
    printf("[%2d]\n", 1234);   // [1234]    ← عرض هرگز برش نمی‌دهد!
    return 0;
}
```

**قانون طلایی عرض**

عرض فقط **حداقل** است؛ اگر عدد بلندتر باشد کامل چاپ می‌شود و چیزی از دست نمی‌رود.

## ۵.۳ — دقت (Precision)

معنای دقت **بر اساس نوع** فرق دارد:

| نوع داده | معنای `.دقت` | مثال |
|-----------|--------------|------|
| float/double | تعداد رقم اعشار (**گرد می‌شود**) | `%.2f` با 3.14159 ← `3.14` |
| صحیح | حداقل تعداد رقم (پر با صفر) | `%.5d` با 42 ← `00042` |
| رشته | حداکثر کاراکترهای چاپی (**برش**) | `%.3s` با "Programming" ← `Pro` |
| `%g` | تعداد ارقام معنادار کل | `%.3g` با 0.001234 ← `0.00123` |

```c
printf("[%.2f]\n", 3.14159);       // [3.14]
printf("[%10.3f]\n", 3.14159);     // [     3.142]  ← عرض ۱۰ شامل نقطه هم هست
printf("[%05.1f]\n", 3.14);        // [003.1]
printf("[%.5d]\n", 42);            // [00042]
printf("[%.3s]\n", "Programming"); // [Pro]
printf("[%8.3s]\n", "Programming");// [     Pro]
printf("[%.10f]\n", 1.0 / 3.0);    // [0.3333333333]
```

**ترکیب عرض و دقت**

`%10.3f` = عرض کل ۱۰ (فاصله‌ها، نقطه و علامت هم حساب می‌شوند)، ۳ رقم اعشار. عدد ۳.۱۴۲ پنج کاراکتر است پس ۵ فاصله اول می‌آید.


### نماد علمی و %g

```c
printf("%e\n", 123456.789);    // 1.234568e+05  (۶ رقم اعشار پیش‌فرض)
printf("%e\n", 0.0001234);     // 1.234000e-04
printf("%g\n", 123456.789);    // 123457        (فرم f کوتاه‌تر شد)
printf("%g\n", 0.00001234);    // 1.234e-05     (فرم e کوتاه‌تر شد)
```

## ۵.۴ — پرچم‌ها (Flags)

| پرچم | اثر | مثال (روی ۴۲) |
|-------|-----|----------------|
| `-` | چپ‌چین (به‌جای راست‌چین پیش‌فرض) | `%-5d` ← `42   ` |
| `+` | چاپ صریح علامت مثبت | `%+d` ← `+42` |
| فاصله (space) | فاصله به‌جای + برای مثبت‌ها | `% d` ← ` 42` |
| `0` | پر کردن با صفر (بعد از علامت) | `%05d` ← `00042`؛ `%04d` با −۲۵ ← `-025` |
| `#` | نمایش پیشوند مبنا / نقطه اعشار | `%#o` با ۸ ← `010`؛ `%#x` با ۲۵۵ ← `0xff`؛ `%#.0f` با ۳ ← `3.` |

```c
printf("[%+d] [%+d]\n", 42, -42);   // [+42] [-42]
printf("[% d]\n", 42);              // [ 42]
printf("[%#x] [%#o]\n", 255, 8);    // [0xff] [010]
```

**تله پرچم #**

`%#o` صفر ابتدای عدد را **اضافه** می‌کند: عدد ۸ در اوکتال `10` است ولی با `#` چاپ می‌شود `010`. طراحان از همین اختلاف ظریف سؤال می‌سازند.

## ۵.۵ — مقدار برگشتی printf

`printf`
یک `int` برمی‌گرداند: **تعداد کاراکترهای چاپ‌شده** (در صورت موفقیت؛ منفی در خطا).

```c
int n = printf("Hello\n");    // چاپ می‌کند Hello
printf("%d\n", n);            // 6  (H-e-l-l-o-\n شامل \n!)
```

```c
printf("%d", printf("Hi"));
// Hi2
```

سؤال کم‌یاب ولی شیک کنکوری.

## ۵.۶ — scanf به‌طور کامل

### سه نوع دستور در رشته قالب scanf

1. **مشخص‌کننده‌های تبدیل** (`%d`, `%s`, ...) — ورودی مربوطه را می‌خوانند.
2. **فضاهای سفید در قالب** (space, `\t`, `\n`) — **صفر یا چند** فضای سفید ورودی را می‌پرند.
3. **کاراکترهای معمولی دیگر** — باید **دقیقاً** در ورودی همان‌جا ظاهر شوند؛ وگرنه تطبیق همان‌جا متوقف می‌شود.

```c
scanf("%d/%d/%d", &y, &m, &d);
// ورودی: 1403/05/12 → y=1403, m=5, d=12  ✓ (اسلش‌ها دقیقاً تطبیق)
// ورودی: 1403 / 05    → بعد از 1403، قالب '/' انتظار اسلش دارد اما
//                        فاصله آمده → توقف؛ فقط y خوانده شد!
```

**نکته ظریف**

فضای سفید ورودی قبل از کاراکتر معمولیِ قالب **به‌طور خودکار پر نمی‌شود** (جز قبل از فضاهای سفیدِ خودِ قالب). پس `"%d/%d"` با ورودی `"5 / 3"` شکست می‌خورد ولی `"%d /%d"` جواب می‌دهد.
```c
scanf("%d /%d", &a, &b);
```

### رفتار مشخص‌کننده‌ها در scanf

| مشخص‌کننده   | چه چیزی می‌خواند                   | توقف                        |
| ------------ | ---------------------------------- | --------------------------- |
| `%d`         | عدد صحیح (علامت اختیاری)           | اولین کاراکتر غیررقمی       |
| `%f` / `%lf` | عدد اعشاری                         | غیررقمی                     |
| `%c`         | **هر کاراکتری حتی فاصله!**         | — (فضای سفید را نمی‌پرد)    |
| `%s`         | رشته بدون فاصله                    | اولین فاصله/tab/خط جدید     |
| `%[...]`     | scanset — فقط کاراکترهای لیست      | اولین خارج از لیست          |
| `%[^...]`    | scanset معکوس — تا دیدن آن کاراکتر | اولین کاراکتر موجود در لیست |

### عرض میدان و مهار انتساب

```c
scanf("%2d%2d", &a, &b);
// ورودی "12345" → a=12, b=34  (و "5" در بافر می‌ماند!)

scanf("%*d%d", &x);
// *d یعنی یک عدد بخوان ولی دور بریز؛ عدد دوم به x می‌رود
```

### scanset — ابزار حرفه‌ای خواندن

```c
char name[30];
scanf("%[^,]", name);          // تا رسیدن به کاما می‌خواند: "Ali Ahmadi"
scanf(",%d", &age);            // کاما را مصرف می‌کند، سن می‌خواند

scanf(" %[^\n]", line);        // کل خط (تا Enter) — الگوی رایج
// فاصله اول: پرش از فضاهای سفید باقی‌مانده (مثل Enter قبلی!)
```

**چرا " %c" با فاصله؟**

`%c` برخلاف بقیه **فضای سفید را نمی‌پرد**. اگر قبلاً با scanf عدد خوانده‌اید، Enter در بافر مانده و `%c` همان Enter را می‌گیرد! راه‌حل: `" %c"` با فاصله اول.


### مقدار برگشتی scanf — ابزار استحکام برنامه

`scanf` تعداد آیتم‌هایی که **موفقانه ذخیره** کرده را برمی‌گرداند؛ اگر ورودی قبل از هر تبدیلی تمام/نامعتبر شود، `EOF` (= −۱):

```c
if (scanf("%d %d", &a, &b) != 2) {
    printf("Invalid input!\n");
}
```

```text
ورودی "5 7"  → برمی‌گرداند 2
ورودی "5 x"  → برمی‌گرداند 1   (x قابل تبدیل به عدد نیست)
ورودی "abc"  → برمی‌گرداند 0
Ctrl+Z/Z (پایان ورودی) → EOF = -1
```

## 💻 تمرین‌های کدنویسی فصل ۵

**تمرین ۱:** جدول ضرب ۱ تا ۱۰ را با ستون‌های منظم (هر عدد در عرض ۴) چاپ کنید.

**پاسخ تمرین ۱**

```c
#include <stdio.h>

int main(void)
{
    for (int i = 1; i <= 10; i++) {
        for (int j = 1; j <= 10; j++) {
            printf("%4d", i * j);
        }
        printf("\n");
    }
    return 0;
}
```
`%4d` باعث می‌شود همه ستون‌ها هم‌عرض باشند (اعداد دو/سه رقمی راست‌چین در عرض ۴). خروجی مرتب بدون هیچ زحمت اضافه‌ای!


**تمرین ۲:** برنامه‌ای بنویسید که خطی به شکل `Reza 18.25 A` دریافت کند (نام، معدل، نمره حرفی) و آن را قالب‌بندی شده چاپ کند: `Name: Reza | GPA: 18.25 | Grade: A`

**پاسخ تمرین ۲**

```c
#include <stdio.h>

int main(void)
{
    char name[30];
    float gpa;
    char grade;

    if (scanf("%29s %f %c", name, &gpa, &grade) != 3) {
        printf("Bad input!\n");
        return 1;
    }

    printf("Name: %s | GPA: %.2f | Grade: %c\n", name, gpa, grade);
    return 0;
}
```
نکته‌ها: `%29s` برای محافظت از سرریز بافر ۳۰تایی (یک خانه برای `\0`)؛ چک مقدار برگشتی scanf؛ `%.2f` برای دقت دو رقم.


**تمرین ۳:** خروجی برنامه زیر را **بدون اجرا** پیش‌بینی کنید:
```c
#include <stdio.h>

int main(void)
{
    printf("[%+d][% d]\n", 7, 7);
    printf("[%#o][%#x]\n", 64, 200);
    printf("[%.4d][%.4s]\n", 95, "Amazing");
    printf("[%09.2f]\n", -12.5);
    return 0;
}
```

**پاسخ تمرین ۳**

```text
[+7][ 7]
[0100][0xc8]
[0095][Amaz]
[-00012.50]
```
تحلیل: `+7` با علامت صریح؛ ` 7` با فاصله. ۶۴ اوکتالی `100` است با پیشوند `#` ← `0100`؛ ۲۰۰ هگز `c8` ← `0xc8`. `%.4d` عدد ۹۵ را با صفر پر می‌کند؛ `%.4s` رشته را برش می‌زند. آخرین: عرض ۹ با پرچم صفر و دقت ۲ — علامت منفی اول، بعد صفرها: `-` + `000` + `12.50` (مجموعاً ۹ کاراکتر).
