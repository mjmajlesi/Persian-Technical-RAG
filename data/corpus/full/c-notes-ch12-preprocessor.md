# فصل ۱۵: پیش‌پردازنده کامل

## ۱۵.۱ — پیش‌پردازنده چیست؟

برنامه قبل از کامپایل شدن، توسط **پیش‌پردازنده** پردازش می‌شود: هر دستوری که با `#` شروع می‌شود (directive). خروجی آن یک **فایل متنی تغییر یافته** است (فقط C!):

```text
main.c ──[پیش‌پردازنده]──► main.i ──[کامپایلر]──► main.s ──► ...

gcc -E main.c        // فقط مرحله پیش‌پردازش؛ خروجی را ببینید!
```

**ذهنیت درست**

پیش‌پردازنده فقط **جایگزینی/بازنویسی متنی** انجام می‌دهد — نه چک نوع، نه معنا. همه خطاهای ماکرو موقع کامپایلِ «متن جایگزین شده» ظاهر می‌شوند و پیام خطا معمولاً گیج‌کننده است.

## ۱۵.۲ — #include

```c
#include <stdio.h>      // جستجو در پوشه‌های سیستم (system headers)
#include "mylib.h"      // اول پوشه فعلی پروژه، بعد سیستم
```

کارکرد: **کل محتوای** فایل سرآیند به‌صورت متنی جایگزین این خط می‌شود.

**چرا include guard؟**

اگر یک header دو بار include شود، تعریف‌ها دوباره می‌آیند ← خطا. راه حل استاندارد:

```c
#ifndef MYLIB_H          // «اگر قبلاً تعریف نشده...»
#define MYLIB_H

/* محتوای هدر */

#endif
```
بار دوم: MYLIB_H تعریف شده → کل بدنه skip می‌شود. (روش مدرن‌تر: `#pragma once` — غیراستاندارد ولی همه‌جا پشتیبانی.)

## ۱۵.۳ — ماکروهای ساده (object-like)

```c
#define PI 3.14159
#define MAX_SIZE 100
#define GREETING "Hello"

double area = PI * r * r;     // بعد از پیش‌پردازش: 3.14159 * r * r
int arr[MAX_SIZE];            // int arr[100]
```

قواعد:
- جایگزینی **متنی خالص** — هیچ نوعی وجود ندارد!
- معمولاً با حروف بزرگ نوشته می‌شوند (قرارداد)
- بدون `=` و بدون `;` (`#define PI 3.14159;` باگ کلاسیک — سمی‌کولن هم جایگزین می‌شود!)
- تا انتهای فایل فعال است مگر `#undef`:

```c
#undef PI        // از اینجا به بعد PI دیگر تعریف نیست
```

### تله سمی‌کولن

```c
#define N 10;
int a[N];       // بعد از جایگزینی: int a[10;] ← خطای کامپایل!
if (x == N) ... // if (x == 10;) ← خطا
```

## ۱۵.۴ — ماکروهای پارامتری (function-like) ⭐⭐⭐

```c
#define SQUARE(x) ((x) * (x))
#define MAX(a, b) ((a) > (b) ? (a) : (b))
#define ABS(x)    ((x) < 0 ? -(x) : (x))

int y = SQUARE(4);      // ((4) * (4)) = 16
int m = MAX(a, b);      // عبارت شرطی درج می‌شود
```

### قانون طلایی: همه پرانتزها الزامی!

بدون پرانتز چه می‌شود؟

```c
#define BAD_SQUARE(x) x * x

BAD_SQUARE(3)        // 3*3 = 9 ✓
BAD_SQUARE(a + b)    // a + b * a + b  ← غلط!! باید (a+b)*(a+b) بود

#define OK_SQUARE(x) ((x) * (x))
OK_SQUARE(a + b)     // ((a + b) * (a + b)) ✓
```

تله دوم — اثر جانبی:

```c
#define MAX(a, b) ((a) > (b) ? (a) : (b))

int i = 5, j = 2;
int m = MAX(i++, j);
// گسترش: ((i++) > (j) ? (i++) : (j))
// i++ دو بار اجرا شد! i=7 و m=6 (یا UB)
// تابع واقعی max(i++, j): i=6 و m=5
```

**ماکرو ≠ تابع**

| جنبه | تابع | ماکرو |
|------|-------|--------|
| ارزیابی آرگومان | یک بار | **هر جای متن که آمده، یک بار!** |
| چک نوع | دارد | ندارد |
| هزینه فراخوانی | دارد | صفر |
| دیباگ | قابل step | نامرئی |


### عملگرهای # و ##

**# (stringize):** تبدیل آرگومان ماکرو به رشته:

```c
#define STR(x) #x
printf("%s\n", STR(hello));      // "hello" چاپ می‌شود
printf("%s\n", STR(2+3));        // "2+3"
```

**## (token pasting):** چسباندن دو توکن:

```c
#define MAKE_VAR(n) var_##n
int MAKE_VAR(1) = 5;             // int var_1 = 5;
int MAKE_VAR(count);             // int var_count;
```

### ترفند دو-سطحی برای گسترش مقدار

```c
#define VERSION 2
#define STR_(x) #x          // سطح داخلی
#define STR(x) STR_(x)      // سطح بیرونی — x اول گسترش می‌شود!

STR(VERSION)   // "2"   ✓
STR_(VERSION)  // "VERSION"  ✗ (بدون گسترش!)
```

## ۱۵.۵ — کامپایل شرطی ⭐⭐

بخش‌هایی از کد بر اساس شرایط زمان کامپایل فعال/غیرفعال شوند:

```c
#ifdef DEBUG                 // «اگر DEBUG تعریف شده...»
    printf("x = %d\n", x);
#endif

#ifndef MAX_LEN              // الگوی مقداردهی مشروط (include guard هم همین)
    #define MAX_LEN 255
#endif

#if SIZE > 100               // عبارت ثابت صحیح
    /* ... */
#elif SIZE == 50
    /* ... */
#else
    /* ... */
#endif
```

سه راه تعریف DEBUG:

```bash
gcc -DDEBUG main.c           # 1) از خط فرمان (-DDEBUG یا -DDEBUG=1)
```

```c
#define DEBUG                // 2) داخل کد قبل از استفاده
```

```c
/* 3) اصلاً تعریف نشود — بلوک ifdef حذف می‌شود */
```

**نکات کنکوری**

- `#ifdef X` فقط **تعریف‌شدن** X را می‌بیند (حتی `#define X 0`!) — برای «مقدار» از `#if X` استفاده کنید.
- بخش‌های حذف‌شده هنوز باید **لکسیکالی سالم** باشند (سمی‌کولن‌ها و کوتیشن‌ها بالانس) ولی نیازی به معتبر بودن نحوی ندارند.
- `defined(X)` داخل `#if`: `#if defined(A) && !defined(B)`.

## ۱۵.۶ — ماکروهای از پیش تعریف‌شده

| ماکرو | مقدار |
|-------|-------|
| `__LINE__` | شماره خط فعلی (عدد) |
| `__FILE__` | نام فایل (رشته) |
| `__DATE__` | تاریخ کامپایل (رشته) |
| `__TIME__` | ساعت کامپایل (رشته) |
| `__STDC__` | ۱ اگر کامپایل استاندارد ANSI باشد |

```c
#define LOG(msg) fprintf(stderr, "[%s:%d] %s\n", __FILE__, __LINE__, msg)
LOG("oops");    // [main.c:42] oops
```

کاربرد واقعی: پیام‌های خطا، assert استاندارد:

```c
#define NDEBUG          // اگر قبل از assert.h: assert خاموش می‌شود
#include <assert.h>

assert(ptr != NULL);    // در release حذف می‌شود
```

## 💻 تمرین‌های کدنویسی فصل ۱۵

**تمرین ۱:** ماکروهای امن بنویسید: MIN(a,b)، SWAP(type, x, y) (با متغیر موقت typed) و ARRAY_LEN(arr).

**پاسخ تمرین ۱**

```c
#define MIN(a, b) ((a) < (b) ? (a) : (b))
#define SWAP(t, x, y) do { t _tmp = (x); (x) = (y); (y) = _tmp; } while (0)
#define ARRAY_LEN(arr) (sizeof(arr) / sizeof((arr)[0]))

/* استفاده: */
int a = 3, b = 8;
SWAP(int, a, b);              /* a=8, b=3 */
double d[7];
size_t n = ARRAY_LEN(d);      /* 7 */
```
الگوی `do { } while(0)` ماکرو را مثل یک دستور واحد رفتار می‌دهد (در if بدون آکولاد هم امن است).


**تمرین ۲:** خروجی برنامه زیر را پیش‌بینی کنید (بدون اجرا):
```c
#include <stdio.h>
#define N 3
#define M (N + 1)
#define SUM (M + M)

int main(void)
{
    printf("%d\n", SUM * 2);
#if N > 2 && defined(M)
    printf("yes\n");
#else
    printf("no\n");
#endif
    return 0;
}
```

**پاسخ تمرین ۲**

خروجی:
```text
16
yes
```
تحلیل: `SUM * 2` → `(M + M) * 2` → `((N + 1) + (N + 1)) * 2` → `(4 + 4) * 2` = ۸×۲ = **۱۶** (پرانتز دور M و SUM نجات‌بخش بود).
`#if N>2 && defined(M)`: ۳>۲ درست و M تعریف شده → `yes`.
