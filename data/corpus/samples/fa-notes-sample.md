# اشاره‌گرها در C (نمونه توسعه — جزئی از اسنپ‌شات نهایی نیست)

## تعریف اشاره‌گر

اشاره‌گر متغیری است که آدرس حافظه متغیر دیگری را نگه می‌دارد.
برای تعریف اشاره‌گر از عملگر `*` استفاده می‌کنیم.

```c
int x = 10;
int *p = &x;
```

## عملگرهای آدرس و مقدار

عملگر `&` آدرس متغیر را برمی‌گرداند و عملگر `*` مقدار موجود در آدرس را می‌خواند.

```c
int y = *p;  /* y برابر 10 می‌شود */
```
