# Source inventory and recorded license labels

This inventory transcribes `source_id`, `origin`, and `license` from the four
`data/corpus/manifest.<pack>.json` files. Origins are local snapshot paths,
not necessarily original publication URLs. No source content or manifest was changed.

**Review flag is a metadata observation, not a legal opinion or a conclusion
about permission.** All entries require independent verification before reuse;
a named license in a manifest is not proof that it covers the snapshot or that
its conditions have been met. Model licenses do not license the corpus.

Flag key: **REVIEW** means the recorded label does not itself specify a
version, a clear redistribution grant, or the governing terms; verify the
original source, applicable terms, version and attribution independently.
